# Deskbar Quest Graphics Pack

Drop PNG sprites into these folders to replace the built-in rectangle art. Keep sprites small and pixel-art friendly; `16x16`, `24x24`, or `32x32` works best.

## Heroes

Place hero sprites here:

```text
assets/heroes/warrior.png
assets/heroes/mage.png
assets/heroes/archer.png
```

## Monsters

Place monster archetype sprites here:

```text
assets/monsters/beast.png
assets/monsters/wing.png
assets/monsters/shield.png
assets/monsters/slime.png
assets/monsters/wisp.png
assets/monsters/mimic.png
assets/monsters/elite.png
```

Sprites are loaded with nearest-neighbor filtering and scaled into the tiny battle scene. Transparent PNG backgrounds are supported.
